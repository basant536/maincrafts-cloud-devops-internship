## ☁️ AWS Deployment Steps
1. Created an S3 bucket.
2. Enabled Static Website Hosting.
3. Uploaded website files.
4. Configured Bucket Policy for public access.
5. Created an Amazon CloudFront Distribution.
6. Connected CloudFront with the S3 Website Endpoint.
7. Verified the website using the CloudFront URL.
